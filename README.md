# VR Box · Quest — сервер для Render

Один Node-сервис делает всё сразу:
- отдаёт игру (`public/index.html`) по адресу твоего сайта;
- API аккаунтов: `/api/register`, `/api/login`, `/api/me`, `/api/save` (облачное сохранение);
- WebSocket: комнаты server #1–#4 (до 50 игроков), позиции игроков, голос только тем, кто ближе 12 м.

## Запуск на Render
1. Залей содержимое этой папки в GitHub-репозиторий (корень репозитория = эта папка).
2. Render → **New → Web Service** → выбери репозиторий.
3. Настройки: Runtime **Node**, Build Command `npm install`, Start Command `npm start` (или используй `render.yaml` через Blueprint).
4. После деплоя открой `https://ТВОЁ-ИМЯ.onrender.com` — игра сама подключится к серверу (адрес берётся из `location.origin`).

Если игру открываешь не с Render, а откуда-то ещё: `https://твой-сайт/index.html?server=https://ТВОЁ-ИМЯ.onrender.com`.


## Важно про папку public
Теперь можно **двумя способами**:

1. **Как раньше** — папка `public/index.html`
2. **Проще** — просто положи `index.html` прямо в корень рядом с `server.js` (папку public можно не создавать)

Оба варианта работают.

## Важно
- **Бесплатный Render не хранит файлы**: аккаунты лежат в `data/users.json` и пропадут при перезапуске/редеплое.
  Чтобы сохранялись — подключи Render Disk (платный) и задай переменную `DATA_FILE=/data/users.json`
  (путь внутри диска), либо замени хранилище на базу данных.
- Бесплатный сервис засыпает после ~15 минут без запросов и просыпается до минуты — игра об этом предупреждает.
- Локально: `npm install && npm start`, открой http://localhost:3000
